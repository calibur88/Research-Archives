## 2 核心计算公式

### 2.1 时空曲率张量（弱场近似）

$$
R_{r0r0} = \frac{GM}{r^3} = \frac{a_{\text{Newton}}}{r} \quad [\text{m}^{-2}]
$$

```python
def curvature_tensor(M, r):
    """计算时空曲率分量 R_r0r0"""
    return G * M / r**3   # m^{-2}
``` <!-- 代码块结束 -->

### 2.2 后牛顿参数

$$
\varepsilon = \frac{GM}{rc^2} = |\Phi| \ll 1
$$

```python
def epsilon(M, r):
    """后牛顿小参数（无量纲）"""
    return G * M / (r * c**2)
``` <!-- 代码块结束 -->

### 2.3 每周期近日点进动

$$
\Delta\omega = \frac{6\pi GM}{c^2 a(1-e^2)} \quad [\text{rad/orbit}]
$$

```python
def perihelion_precession(M, a, e):
    """GR近日点进动（弧度/周期）"""
    return (6 * np.pi * G * M) / (c**2 * a * (1 - e**2))
``` <!-- 代码块结束 -->

### 2.4 轨迹分离（实际空间偏移）

$$
\Delta s = a \cdot N \cdot \Delta\omega \quad [\text{m}]
$$

```python
def trajectory_separation(a, N, M, e):
    """N圈后的牛顿-GR实际轨迹分离（米）"""
    delta_phi = perihelion_precession(M, a, e)
    return a * N * delta_phi
``` <!-- 代码块结束 -->

### 2.5 投影偏移（参考距离 D 处）

$$
\Delta s_{\text{proj}} = D \cdot (N \cdot \Delta\omega) \quad [\text{m}]
$$

### 4.2 当前观测限制

- 现有基线（~4年）：累积分离 ~2,000 km，信噪比 <0.3σ，不可检测。
- Hipparcos–Gaia联合（~30年跨度）：基本达到 8σ 要求，但需谨慎处理系统误差。

### 4.3 系统误差风险

- 恒星活动周期：巴纳德星自转周期约 8.8 年，与 8 年观测窗口存在潜在共振，可能产生类行星信号假象。
- 多仪器交叉验证：ESPRESSO + MAROON-X 联合可有效降低径向速度系统误差。

### 4.4 星斑活动与虚假信号分析

巴纳德星是一颗高活动红矮星，表面覆盖强星斑（覆盖面积约10–20%）。星斑随自转（周期约145天）周期性变化，产生的径向速度（RV）信号可能伪装成行星信号，其谐波在傅里叶频谱中表现为多个峰值。

| 观测周期 | 真实来源 | 整数比 | 物理机制 |
| -------- | -------- | ------ | -------- |
| 11天 | 145.4/13 = 11.2天 | 13:1 | 13个星斑群 |
| 20天 | 145.4/7 = 20.8天 | 7:1 | 7个星斑结构 |
| 24天 | 145.4/6 = 24.2天 | 6:1 | 6个大星斑 |

这些虚假信号周期（11、20、24天）与已知行星的轨道周期（2.34–6.74天）**不重叠**，但仍可能干扰较长周期信号的提取。在分析GR引起的微小轨道进动时，必须利用多波段测光同步监测星斑演化，并采用高斯过程回归等方法建模星斑噪声，以避免系统偏差。

## 5 主要结论

### 5.1 理论层面

- 弱场近似严格成立：epsilon ~ 1e-7 << 1，GR计算可靠。
- 曲率量级显著：R_{r0r0} ~ 1e-10 m^{-2}，比地球附近大13个数量级。
- 进动可累积：30年后总进动角度可达数十角秒，轨迹分离进入可探测范围。

### 5.2 观测层面

- 当前数据支持牛顿近似：4年基线内GR效应淹没在噪声中。
- 长期（>30年）观测将能检测弯曲时空效应，GRAVITY+ 或 Gaia 最终数据有望达到 8σ。
- 共振链稳定：行星周期比 9.4:12.6:15.8:25.9 形成平运动共振，相对论扰动小于共振宽度，不影响系统长期稳定性。
- **星斑活动**：需谨慎排除恒星表面活动产生的虚假RV信号（11、20、24天谐波），建议结合测光与RV联合建模。

### 5.3 物理意义

- 巴纳德星是理想的弱场广义相对论实验室，可检验后牛顿修正。
- 参考系投影效应：同样的相对论进动，在行星轨道半径上仅产生数百公里偏移，但在太阳系尺度（8 AU）投影下放大至十几万公里，成为天体测量可及的目标。
- 验证方法：比较牛顿预报与GR预报的长期（30–50年）天体测量轨迹，偏差应当符合 516 km/year 的漂移率。
