2. 核心安全机制

2.1 数学单向性（自指陷阱防护）
密钥派生链：

```
种子 (TPM) 
    ↓ HKDF-SHA256(t_global)
参数集 Θ_t = {U_t, P_t, M_t, dt_t, n_t}
    ↓ SSF演化
模拟波形 s(t)
```

不可逆性证明：
- 极分解：T = UP，其中 U 酉矩阵，P 正定
- 信息损失：U 仅保留 T 的旋转信息，P 的伸缩信息完全丢失
- 欠定方程：观测波形维度（64 IQ采样）<< 未知参数维度（4096复数），且叠加信道噪声与SSF非线性色散

结论：攻击者截获波形后，反解 U 或 T 在计算上不可行（NP-hard病态逆问题）。

2.2 模拟传输层
一旦设备入网，所有数据帧转换为物理层模拟信号：

```c
// 发送端（路由器）
void ssf_transmit(payload, Θ_t) {
    // 1. 数字预处理（仅在安全岛内）
    psi = P_t * QPSK(payload);      // 振幅预补偿
    psi = U_t * psi;                // 酉变换（混沌化）
    
    // 2. SSF演化（色散+非线性）
    for(step=0; step<n_t; step++) {
        FFT(psi);
        psi[k] *= exp(-i * k²/(2*M_t) * dt_t);  // 二次相位调制
        IFFT(psi);
    }
    
    // 3. 模拟输出（DAC）
    tx_iq = normalize(psi);         // 仅IQ采样点流出芯片
    rf_transmit(tx_iq);             // 空中无数字密钥痕迹
}
```

安全特性：
- 零数字足迹：空中接口无802.11管理帧明文、无密钥协商包、无固定前导码
- 流量伪装：SSF色散效应使信号频谱接近高斯噪声，传统协议分析工具（Wireshark等）无法识别为Wi-Fi帧

3. 密钥进化与同步

3.1 时间驱动的密钥进化
- 全局时钟：t{global} 以帧序号计（1ms/帧），路由器信标广播 明文 t{global}（仅作索引，无秘密）
- 进化触发：每检测到入侵（谱间隙异常），t{global} \mathrel{+}= \Delta，强制进入下一密钥周期
- 前向安全：即使当前 \Theta_t 被泄露（理论上的侧信道极限攻击），过往流量因使用 \Theta{t-1}, \Theta{t-2} 而无法解密

3.2 设备同步协议

```c
// 接收端（手机）同步算法
void sync_frame(rx_iq) {
    for(delta = 0; delta <= 10; delta++) {  // 容忍10帧丢包
        K_local = KDF(seed, t_local + delta);
        if (validate_magic(rx_iq, K_local) == OK) {
            t_local += delta;
            return SYNCED;
        }
    }
    return OUT_OF_SYNC;  // 触发重新扫码配对
}
```

防DoS设计：攻击者无法通过伪造 t{global} 使设备失步——恶意 t 会导致密钥不匹配，数据无法解密，但设备会尝试 t \pm 10 的窗口，失败后保持静默而非崩溃。

4. 入网与授权（动态二维码）

4.1 实时二维码机制
内容格式：

```
QR_data = AES-GCM(K_auth)[种子分片 || 设备ID || 权限掩码 || 时间戳 || nonce]
```

- K{auth}：由TPM根据主种子+当前小时派生，每小时自动轮换
- 有效期：5分钟（时间戳过期作废），单次使用（nonce防重放）
- 传输方式：屏幕显示（防远程截屏需物理接近）或NFC触碰（<10cm，防偷拍）

4.2 分级授权

二维码类型	派生密钥	有效期	权限	
主人码	主种子	永久	全功能，可管理访客	
访客码	子种子（HKDF派生）	24小时	限速，隔离VLAN，不可访问管理界面	
临时码	一次性令牌	1小时	仅互联网访问，禁止内网探测	

撤销能力：主人手动刷新二维码（TPM生成新nonce序列），旧授权立即失效，无需等待过期。

5. 入侵检测与主动防御

5.1 谱间隙检测（物理层入侵识别）
合法信号经过 U_t 变换后，在特定子空间（码字位置）聚集能量；攻击者无 U_t 时，信号呈均匀分布。

```c
bool intrusion_detect(rx_iq, U_t) {
    proj = U_t^H * rx_iq;           // 匹配滤波投影
    
    E_codeword = sum(|proj[2k]|²);  // 偶数位能量（合法位置）
    E_mid      = sum(|proj[2k+1]|²);// 奇数位能量（间隙）
    
    gap = (E_codeword - E_mid) / E_codeword;
    return (gap < 0.2);             // 理论值0.41，低于阈值判定为入侵
}
```

5.2 反向定位与压制
一旦连续3次检测到入侵：

1. DOA估计：利用4天线相位差计算到达角 \theta
   
```c
   delta_phi = arg(s_1 * conj(s_0));
   theta = asin(delta_phi * lambda / (2*pi*d));  // 精度±5度
   ```

2. 波束成形归零：调整4天线权重，在 \theta 方向形成深衰落（null steering），攻击者方向信号衰减30dB

3. 射频指纹拉黑：记录攻击者设备的载波频偏（CFO）与IQ不平衡特征，即使更换MAC也拒绝服务

4. 蜜罐诱导（可选）：向攻击者方向发射虚假 U{fake} 信号，诱导其浪费算力破解无效密钥

6. 威胁模型与安全边界

6.1 适用场景
- 家用/小型办公：设备数量<50，物理环境可控（门锁、监控）
- 威胁等级： opportunistic attackers（机会主义攻击者），非国家级APT

6.2 防护边界

攻击类型	防护效果	备注	
远程网络攻击	完全免疫	无在线数字攻击面，无协议状态机	
侧信道分析	高抗性	U矩阵不存储，仅实时计算；高维参数无法从64采样点重构	
流量分析	完全免疫	波形呈噪声特性，无固定协议特征	
中间人/重放	免疫	无静态密钥可窃听，时间戳防重放	
降级攻击	免疫	固件写死拒绝非SSF关联，宁可断网不回退WPA3	
物理设备窃取	依赖环境	TPM防拆封自毁，但专业实验室冷冻提取不可防（需物理安保）	

6.3 极限攻击场景
- 专业实验室级：拆芯片、冷冻内存、激光读取TPM熔丝 → 需物理安保（锁、监控）防范
- 量子计算：SSF不依赖大数分解/离散对数，Shor算法无效；Grover算法对256位种子提供平方根加速，但需2^128次操作，仍不可行
