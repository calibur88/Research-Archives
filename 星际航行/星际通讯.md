## 3. 核心定理体系

### 3.1 酉性定理体系

#### 定理 2.1（离散傅里叶变换的酉性）

**陈述**：设 $\mathcal{F} \in \mathbb{C}^{N \times N}$ 为离散傅里叶变换矩阵，其元 $\mathcal{F}_{n,k} = \frac{1}{\sqrt{N}} e^{2\pi i n k / N}$（索引 $n,k \in \{-D,\dots,D\}, N=2D+1$），则 $\mathcal{F}$ 为酉矩阵：
$$\mathcal{F}^\dagger \mathcal{F} = \mathcal{F} \mathcal{F}^\dagger = I.$$

**证明**：由单位根正交性，
$$(\mathcal{F}^\dagger \mathcal{F})_{k,k'} = \frac{1}{N} \sum_{n=-D}^{D} e^{-2\pi i n k / N} e^{2\pi i n k' / N} = \frac{1}{N} \sum_{n=-D}^{D} e^{2\pi i n (k'-k)/N} = \delta_{k,k'}.$$
$\square$

#### 定理 2.2（SSF 单步演化算符的酉性）

**陈述**：设单步演化算符
$$U_{\text{step}} = \mathcal{F}^{-1} \circ \exp\left(-i \frac{k^2}{2M}\Delta t\right) \circ \mathcal{F},$$
其中对角矩阵 $D_{k,k} = \exp\left(-i \frac{k^2}{2M}\Delta t\right)$ 满足 $|D_{k,k}| = 1$。则 $U_{\text{step}}$ 为酉算符，且条件数 $\kappa(U_{\text{step}}) = 1$。

**证明**：$\mathcal{F}$ 酉（定理 2.1），$D$ 为酉对角矩阵（因 $|e^{-i\theta}| = 1$）。酉矩阵的乘积仍酉，故 $U_{\text{step}} = \mathcal{F}^\dagger D \mathcal{F}$ 酉。条件数 $\kappa = \|U\|_2 \|U^{-1}\|_2 = 1 \cdot 1 = 1$。$\square$

#### 推论 2.3（SSF 多步演化算符的酉性）

**陈述**：总演化算符 $U_{\text{SSF}} = (U_{\text{step}})^{n_s}$ 满足酉性 $U_{\text{SSF}}^\dagger U_{\text{SSF}} = I$，且 $\kappa(U_{\text{SSF}}) = 1$。

**证明**：酉矩阵的幂仍酉。$U_{\text{SSF}}^\dagger = (U_{\text{step}}^\dagger)^{n_s} = (U_{\text{step}}^{-1})^{n_s} = U_{\text{SSF}}^{-1}$。$\square$

#### 注 2.1（SSF 传播子的非局域化性质）

**陈述**：$U_{\text{SSF}}$ 描述自由空间波包扩散，其矩阵元 $|(U_{\text{SSF}})_{n,d}|$ 随 $n_s$ 增加按高斯型展宽 $\sim \exp\left(-\frac{(n-d)^2}{2\sigma^2}\right)$，其中 $\sigma^2 \propto \frac{n_s \Delta t}{M}$。**不具备与 $n_s$ 无关的指数局域化**。

### 3.2 极分解与局域化定理

#### 定理 2.4（Toeplitz 信道矩阵的指数衰减）

**陈述**：设 Toeplitz 矩阵 $T \in \mathbb{C}^{N \times N}$，$T_{n,d} = W_{n-d}$，其核函数满足指数衰减：
$$|W_\Delta| \leq C_0 e^{-\alpha |\Delta|}, \quad \alpha > 0.$$
则 $T$ 为有效带宽矩阵，且其奇异值分布满足 Szegő 第一极限定理。

**证明**：由定义，$T$ 的符号 $f(\theta) = \sum_{\Delta} W_\Delta e^{-i\theta\Delta}$ 在 $|e^{i\theta}| = 1$ 邻域内解析（因指数衰减保证解析半径 $>0$）。$\square$

#### 定理 2.5（极分解酉矩阵的指数局域化——Widom 定理）

**陈述**：设 $T$ 为定理 2.4 中的 Toeplitz 矩阵，且符号 $f(\theta)$ 满足 $|f(\theta)| \geq c > 0$（无零点）。令极分解 $T = U_{\text{polar}} P$，其中 $P = (T^\dagger T)^{1/2}$ 正定，$U_{\text{polar}} = T P^{-1}$ 酉。则存在常数 $C > 0$ 和 $\gamma_{\text{polar}} > 0$ 使得：
$$|(U_{\text{polar}})_{n,d}| \leq C e^{-\gamma_{\text{polar}} |n-d|}.$$

**证明概要**：
1. $T^\dagger T$ 为自伴 Toeplitz 矩阵，符号 $|f(\theta)|^2$ 解析无零点；
2. 由 Widom 定理，$(T^\dagger T)^{-1/2}$ 的矩阵元满足指数衰减；
3. $U_{\text{polar}} = T \cdot (T^\dagger T)^{-1/2}$ 为两个指数衰减 Toeplitz 型矩阵的乘积，卷积保持指数衰减性。$\square$

#### 定理 2.6（总酉编码器的有效局域化）

**陈述**：设 $U_{\text{total}} = U_{\text{SSF}} \cdot U_{\text{polar}}$。若 $U_{\text{SSF}}$ 的扩散宽度 $\sigma_{\text{SSF}}$ 满足 $\sigma_{\text{SSF}} \ll 1/\gamma_{\text{polar}}$（即演化步数 $n_s$ 受限或 $M$ 较大），则 $U_{\text{total}}$ 满足**准指数局域化**：
$$|(U_{\text{total}})_{n,d}| \leq C_{\text{eff}} e^{-\gamma_{\text{eff}} |n-d|},$$
其中 $\gamma_{\text{eff}} = \gamma_{\text{polar}} - O(1/\sigma_{\text{SSF}}) > 0$。

**物理意义**：$U_{\text{polar}}$ 将信号预编码为局域波包，$U_{\text{SSF}}$ 的有限步数演化仅引起可控扩散，不足以破坏局域化结构。$\square$

#### 注 2.2（准指数局域化的严格数学含义）

定理 2.6 所称的"准指数局域化"是工程近似表述。严格数学上，$U_{\text{total}}$ 的矩阵元衰减形式为卷积积分：
$$|(U_{\text{total}})_{n,d}| \sim \left| \int_{-\infty}^{\infty} e^{-\frac{(n-m)^2}{2\sigma_{\text{SSF}}^2}} \cdot e^{-\gamma_{\text{polar}}|m-d|} dm \right|$$

该结果在核心区域呈高斯型，在远场尾区呈指数型。当 $\sigma_{\text{SSF}} \ll 1/\gamma_{\text{polar}}$ 时，远场指数尾主导整体衰减行为，故可近似为指数局域化，有效衰减率 $\gamma_{\text{eff}} \approx \gamma_{\text{polar}} - O(1/\sigma_{\text{SSF}})$。

### 3.3 QEC 谱间隙定理

#### 定理 2.7（码字交叠矩阵的本征值）

**陈述**：设 $U_{\text{total}}$ 满足定理 2.6 的有效局域化，码字集 $\mathcal{D} = \{d_0 + j\delta\}_{j=0}^{K-1}$。对任意位置 $n$，定义交叠向量 $\mathbf{v}(n) = [U_{n,d_0}, \dots, U_{n,d_{K-1}}]^T \in \mathbb{C}^K$，则错误投影算子 $\mathbf{W}(n) = \mathbf{v}(n)\mathbf{v}(n)^\dagger$ 为秩-1 矩阵，其最大本征值为：
$$\lambda_{\max}(n) = \|\mathbf{v}(n)\|^2 = \sum_{j=0}^{K-1} |U_{n,d_j}|^2.$$

**证明**：由定义直接计算，$\mathbf{W}(n)$ 为外积矩阵，秩为 1，唯一非零本征值为 $\mathbf{v}(n)^\dagger \mathbf{v}(n) = \sum_j |U_{n,d_j}|^2$。$\square$

#### 定理 2.8（谱间隙正定性）

**陈述**：设 $U_{\text{total}}$ 满足列归一化 $\sum_n |U_{n,d}|^2 = 1$ 及指数衰减 $|U_{n,d}| \leq C e^{-\gamma|n-d|}$。定义谱间隙：
$$\Delta = \min_{j} \lambda_{\max}(d_j) - \max_{m \in \mathcal{M}} \lambda_{\max}(m),$$
其中 $\mathcal{M} = \{d_j + \delta/2\}$ 为相邻码字中点。当 $\gamma\delta \gtrsim 0.2$ 且 $C \approx 1$ 时，存在函数 $\Phi(\gamma, \delta, C) > 0$ 使得：
$$\Delta \geq \Phi(\gamma, \delta, C) > 0.$$
数值上，标准配置下 $\Delta \approx 0.41$。

**证明**：

**步骤 1（码字中心下界）**：
由行归一化（$U_{\text{total}}$ 酉）及指数衰减：
$$|U_{d_j,d_j}|^2 = 1 - \sum_{n \neq d_j} |U_{n,d_j}|^2 \geq 1 - \frac{2C^2 e^{-2\gamma}}{1-e^{-2\gamma}}.$$
利用码字间距 $\delta$ 改进：非码字列贡献受 $\delta$ 隔离，实际：
$$|U_{d_j,d_j}|^2 \geq 1 - \frac{2C^2 e^{-2\gamma\delta}}{1-e^{-2\gamma\delta}}.$$
故：
$$\lambda_{\max}(d_j) \geq 1 - \frac{2C^2 e^{-2\gamma\delta}}{1-e^{-2\gamma\delta}}. \tag{1}$$

**步骤 2（中点值上界）**：
对 $m = d_j + \delta/2$，有 $|m-d_k| \geq \delta/2 + \delta|j-k|$。故：
$$\lambda_{\max}(m) \leq C^2 \sum_{k=-\infty}^{\infty} e^{-2\gamma\delta|k+1/2|} = \frac{2C^2 e^{-\gamma\delta}}{1-e^{-2\gamma\delta}}. \tag{2}$$

**步骤 3（间隙下界）**：
联立 (1)(2)：
$$\Delta \geq 1 - \frac{2C^2(e^{-2\gamma\delta} + e^{-\gamma\delta})}{1-e^{-2\gamma\delta}}.$$
当 $\gamma\delta \gtrsim 0.2$ 且 $C \approx 1$ 时，右端为正。$\square$

### 3.4 安全性定理

#### 定理 2.9（极分解攻击者误码率下界）

**陈述**：设合法接收端已知 $U_{\text{total}}$ 与 $P$，攻击者仅知信道结构而不知密钥参数。则攻击者最优估计的误码率满足：
$$\text{BER}_{\text{adv}} \geq 1 - \frac{1}{|\mathcal{C}|},$$
其中 $|\mathcal{C}|$ 为星座大小（QPSK 时 $|\mathcal{C}|=4$，故 BER $\geq 75\%$）。若考虑信道矩阵条件数 $\kappa(T)$，迫零攻击下：
$$\text{BER}_{\text{adv}} \geq \frac{1}{2}\left(1 - \frac{1}{\sqrt{\kappa(T)}}\right).$$

**证明**：$U_{\text{polar}}$ 在密钥空间近似 Haar 随机分布，攻击者等效面对随机酉旋转后的星座，符号错误概率趋于均匀分布 $1/|\mathcal{C}|$。$\square$

#### 定理 2.10（QEC 层与安全性兼容性）

**陈述**：QEC 层参数（$\delta, K, \Delta$）可公开而不削弱安全性。攻击者即使获知这些参数，因不知 $U_{\text{total}}$，其解码结果仍完全随机，$\text{BER}_{\text{adv}} \geq 75\%$。

**证明**：QEC 仅对已知 $U_{\text{total}}$ 的合法接收端提供纠错增益。攻击者的错误分布不受 QEC 影响，仍由定理 2.9 的信息论下界控制。$\square$

### 3.5 文件传输定理

#### 定理 2.11（Repeat3 文件头保护）

**陈述**：设文件头长度为 $L$ bytes，经 Repeat3 编码后长度为 $3L$，与载荷合并传输。若信道误码率 $p < 1/2$（每 byte），则解码后文件头错误概率：
$$P_{\text{header\_error}} \leq L \cdot (3p^2(1-p) + p^3) \approx 3Lp^2.$$
当 $p=1\%$ 时，$P_{\text{header\_error}} \approx 0.03L \ll 1$（实际 100% 恢复）。

**证明**：每 byte 需至少 2 个副本错误才会导致解码错误，概率为 $3p^2(1-p) + p^3 \approx 3p^2$。Union bound 得总错误概率上界。$\square$

### 3.6 混沌增强定理（C-SSF 层）

#### 定理 8.1（辛演化保持）

**陈述**：设 $U_{\text{NL}}$ 为 NL-SSF 单步算符，则其在离散化辛积分格式下保持辛形式：
$$U_{\text{NL}}^T J U_{\text{NL}} = J + O(\Delta t^3), \quad J = \begin{pmatrix} 0 & I \\ -I & 0 \end{pmatrix}$$

**证明**：NL-SSF 采用分步算符（Strang 分裂），色散部分与非线性部分各自保持辛结构，合成后保持至 $O(\Delta t^3)$。$\square$

#### 推论 8.2（概率守恒与酉性兼容）

**陈述**：尽管 $U_{\text{NL}}$ 不再为线性酉矩阵，保守混沌保持 $L^2$ 范数守恒：
$$\|\psi(t)\|^2 = \|\psi(0)\|^2 = 1$$
数值演化中条件数 $\kappa = 1$ 的性质得以保留，与主文档定理 2.2 的酉性框架完全兼容。

**证明**：非线性相位因子 $\exp(-i\kappa|\psi|^2\Delta t)$ 保持 $|\psi|$ 不变，FFT 为酉变换，故范数守恒。$\square$

#### 定理 8.3（李雅普诺夫时间壁垒）

**陈述**：设攻击者以精度 $\epsilon$（受限于量子不确定性 $\epsilon \geq \hbar/2$ 等效噪声）克隆设备初始条件，每步演化物理时间为 $\Delta t$，则其预测保持有效的时间上限为：
$$t_{\text{predict}} \leq \frac{\Delta t}{\lambda_{\max}} \ln\left(\frac{\Delta_{\text{tolerance}}}{\epsilon}\right)$$

其中 $\Delta_{\text{tolerance}}$ 为 SSF 解码容差（通常 $10^{-6}$）。

**证明**：  
由李雅普诺夫定义，误差演化满足 $\|\delta\psi(n)\| = \epsilon e^{\lambda_{\max} n}$。  
当 $\|\delta\psi(n)\| > \Delta_{\text{tolerance}}$，攻击者预测信号与合法信号偏差超过纠错能力，触发 BER $\geq 75\%$（定理 2.9）。  
解得步数上限 $n_{\text{predict}} = \frac{1}{\lambda_{\max}} \ln\left(\frac{\Delta_{\text{tolerance}}}{\epsilon}\right)$，乘以 $\Delta t$ 得时间上限。 $\square$

**物理意义**：即使攻击者拥有量子计算能力，也无法在**每个 $\Delta t$ 时间步内**完成混沌系统的实时求解以伪造信号。

**典型参数**（$M=4.0$，$\Delta t=0.1$ s，$n_s=40$，$\kappa=3.0$）：
- 李雅普诺夫指数 $\lambda_{\max} \approx 1.69$（每步）
- 量子极限等效 $\epsilon \sim 10^{-15}$
- 预测有效期步数：$n_{\text{predict}} \approx \frac{1}{1.69} \ln(10^{21}) \approx 28.6$ 步
- 时间：$t_{\text{predict}} \approx 28.6 \times 0.1 = 2.86$ 秒

若演化步数 $n_s > n_{\text{predict}}$，则攻击者在信号帧传输完成前即已完全失步。

#### 定理 8.4（熵增绑定）

**陈述**：混沌系统的 Kolmogorov-Sinai 熵 $h_{\text{KS}}$ 与李雅普诺夫指数满足 Pesin 恒等式：
$$h_{\text{KS}} = \sum_{\lambda_i > 0} \lambda_i \geq \lambda_{\max}$$

攻击者试图"回溯"混沌状态以降低熵，等价于在有限时间内完成与 $e^{\lambda_{\max} t}$ 成正比的计算量，这违反热力学第二定律对信息处理的限制（Landauer 原理）。

#### 定理 8.5（C-SSF 完备安全性）

**陈述**：在以下物理假设下，C-SSF 协议提供信息论安全：
1. **热力学第二定律成立**（熵增原理）
2. **量子不确定性原理成立**（$\Delta x \Delta p \geq \hbar/2$）
3. **经典测量极限存在**（亚微角秒不可达）

**安全性**：任何局限于本宇宙物理定律的攻击者，无论其计算能力（包括量子计算机），均无法在实时时间尺度内伪造有效信号。

**证明概要**：
- 经典层：定理 2.9（BER $\geq 75\%$）
- 量子层：不可克隆定理（测量必扰动）
- 混沌层：定理 8.3（李雅普诺夫时间壁垒）

三层防御正交，攻击者需同时突破相对论、量子力学、热力学——即具备**重启宇宙或操控时间**的能力。$\square$

## 4. 协议架构

### 4.1 经典 SSF 协议

#### 4.1.1 传播理论

**自由粒子哈密顿量**：
$$\hat{H} = -\frac{1}{2M}\frac{\partial^2}{\partial x^2}$$

**动量空间对角化**：
$$E(k) = \frac{k^2}{2M}, \quad U(k) = \exp\left(-i \frac{k^2}{2M} \Delta t\right)$$

**分步傅里叶演化**（单步）：
$$\psi(x, t+\Delta t) = \mathcal{F}^{-1}\left[ e^{-i k^2 \Delta t / 2M} \cdot \mathcal{F}[\psi(x,t)] \right]$$

**完整演化**（$n_s$ 步）：
$$\psi(x, T) = \left( \mathcal{F}^{-1} \circ e^{-i k^2 \Delta t / 2M} \circ \mathcal{F} \right)^{n_s} \psi(x, 0)$$

#### 4.1.2 极分解安全架构

信道矩阵 $T$（Toeplitz 构造）进行极分解：
$$T = U \cdot P, \quad P = (T^\dagger T)^{1/2}$$

**安全机制**：
- **$U$**：酉密钥矩阵，$U^\dagger U = I$，条件数 $\kappa = 1$
- **$P$**：正定振幅预补偿矩阵
- **自指陷阱**：奇异值简并处，$T$ 的微小扰动导致 $U$ 的随机旋转

**星际信道模型**：
$$\psi_{\text{rx}}(x_n) = \left( \psi(x, T) + \eta(x) \right) \cdot \eta_n$$

其中 $\eta(x) \sim \mathcal{CN}(0, \sigma^2)$，消光系数：
$$\eta_n = \begin{cases} 0.3 & n < 0 \ (\text{紫外波段}) \\ 1.0 & n \geq 0 \ (\text{可见波段}) \end{cases}$$

#### 4.1.3 编码流程

**步骤 1：QPSK 符号映射**
$$\chi_m \in \left\{ \frac{1+i}{\sqrt{2}}, \frac{-1+i}{\sqrt{2}}, \frac{-1-i}{\sqrt{2}}, \frac{1-i}{\sqrt{2}} \right\}, \quad m \in \{0,1,2,3\}$$

**步骤 2：初始波函数制备**
$$\rho_n = \chi_{s_n}, \quad \psi_0 = \sqrt{\frac{P_{\text{target}}}{\sum|\rho|^2}} \cdot \rho$$

**步骤 3：振幅预补偿**
$$\psi_1 = P \cdot \psi_0$$

**步骤 4：酉密钥变换**
$$\psi_2 = U \cdot \psi_1$$

**步骤 5：FFT 蝴蝶演化（$n_s$ 步）**
$$\psi_{\text{tx}} = \left( \mathcal{F}^{-1} e^{-i k^2 \Delta t / 2M} \mathcal{F} \right)^{n_s} \psi_2$$

#### 4.1.4 解码流程

**步骤 1：反向 FFT 相位演化**
$$\tilde{\psi} = \left( \mathcal{F}^{-1} e^{+i k^2 \Delta t / 2M} \mathcal{F} \right)^{n_s} \psi_{\text{rx}}$$

**步骤 2：酉密钥解调**
$$\tilde{\psi}' = U^\dagger \cdot \tilde{\psi}$$

**步骤 3：振幅解调**
$$\tilde{\rho} = P^{-1} \cdot \tilde{\psi}'$$

**步骤 4：硬判决**
$$\hat{s}_n = \arg\min_{m} \left| \tilde{\rho}_n - \chi_m \right|$$

#### 4.1.5 文件头保护机制

**Repeat3 编码**：
$$\text{传输数据} = [\text{Header}] \times 3 + [\text{Payload}]$$

**字节级多数表决解码**：
$$\hat{h}_i = \text{majority}\{h_i^{(1)}, h_i^{(2)}, h_i^{(3)}\}$$

**性能指标**（以 128×128 BMP 为例）：
- 原始大小：49,206 bytes
- 文件头：54 bytes → 重复 3 次 = 162 bytes
- 额外开销：108 bytes（0.22%）
- 纠错能力：每字节可纠正 1 bit 错误
- 低 BER（1%）信道下文件头恢复率：100%

### 4.2 Q-SSF 量子协议

#### 4.2.1 量子傅里叶变换

$$\mathcal{F} = \frac{1}{\sqrt{N}}\sum_{n,k} e^{2\pi i nk/N} |k\rangle\langle n|$$

复杂度 $O(\log^2 N)$。

#### 4.2.2 酉编码器构造

**总酉算子**：
$$U_{\text{total}} = U_{\text{SSF}} \cdot U_{\text{polar}}$$

其中：
- $U_{\text{SSF}} = \left( \mathcal{F}^\dagger \cdot \hat{P}_{\text{phase}} \cdot \mathcal{F} \right)^{n_s}$
- $\hat{P}_{\text{phase}} = \sum_{k} e^{-i k^2 \Delta t / 2M} |k\rangle\langle k|$
- $U_{\text{polar}}$ 来自信道矩阵极分解

**初始态制备**：
$$|\psi_{\text{base}}\rangle = \frac{P |j\rangle}{\sqrt{\langle j|P^2|j\rangle}}$$

**编码态**：
$$|\psi_{\text{tx}}\rangle = U_{\text{total}} |d_j\rangle$$

#### 4.2.3 解码

接收端构造 $U_{\text{total}}^\dagger = U_{\text{polar}}^\dagger U_{\text{SSF}}^\dagger$：

$$|\psi_{\text{dec}}\rangle = U_{\text{total}}^\dagger |\psi_{\text{rx}}\rangle$$

投影测量至 $\{|j\rangle\}$ 基，多次测量多数投票恢复信息。

#### 4.2.4 安全性

- **不可克隆定理**：单光子态无法复制，测量必扰动
- **参数-算子纠缠**：$M, \Delta t, n_s$ 同时控制 $U_{\text{SSF}}$ 与 $U_{\text{polar}}$
- **攻击者 BER**：$\geq 75\%$（信息论下限），密钥空间 $\geq 2^{180}$

---

### 4.3 Q-SSF 量子纠错编码（QEC）

#### 4.3.1 准指数局域化

$$|(U_{\text{total}})_{n,d}| \leq C e^{-\gamma|n-d|}$$

衰减率 $\gamma > 0$ 由 $M, \Delta t, n_s$ 决定，实际为准指数衰减（见注 2.2）。

#### 4.3.2 逻辑态构造

**码字索引**（等间距）：
$$d_j = d_0 + j\delta, \quad j = 0,\dots,K-1$$

**逻辑态**：
$$|\text{logical}_j\rangle = U_{\text{total}} |d_j\rangle$$

**码率**：
$$R = \frac{K}{N} \approx \frac{1}{\delta}$$

#### 4.3.3 谱间隙错误检测

**重叠矩阵本征值**：
$$\lambda_{\max}(n) = \sum_{j=0}^{K-1} |(U_{\text{total}})_{n,d_j}|^2$$

**谱间隙**：
$$\Delta = \lambda_{\max}(n_c) - \lambda_{\max}(n_m)$$

其中 $n_c$ 为码字中心，$n_m$ 为相邻码字中点。

**错误检测准则**：
- 若 $\min_j |n - d_j| < \delta/2$，判为逻辑值 $j$
- 若 $\min_j |n - d_j| \geq \delta/2$，触发错误标志

#### 4.3.4 与安全性兼容性

QEC 层参数（$\delta, K, \Delta$）可公开。攻击者不知 $U_{\text{total}}$ 时，QEC 无法提供纠错增益，BER 仍 $\geq 75\%$。

---

### 4.4 C-SSF 混沌增强层（第三重防御）

#### 4.4.1 非线性分步傅里叶变换（NL-SSF）

在标准 SSF 基础上引入 Kerr 型非线性：

$$
i\frac{\partial \psi}{\partial t} = \underbrace{-\frac{1}{2M}\frac{\partial^2 \psi}{\partial x^2}}_{\text{色散}} + \underbrace{\kappa |\psi|^2 \psi}_{\text{非线性/混沌源}}
$$

**离散演化算符**（单步）：
$$
U_{\text{NL}} = \mathcal{F}^{-1} \circ \exp\left(-i \frac{k^2}{2M}\Delta t\right) \circ \mathcal{F} \circ \exp\left(-i \kappa |\psi|^2 \Delta t\right)
$$

**混沌条件**：当 $\kappa \cdot P_{\text{avg}} \cdot n_s > \Lambda_{\text{critical}}$（临界累积非线性），系统进入保守混沌区。

#### 4.4.2 实时混沌密钥流

**合法通信流程**：
1. **预共享初始条件**：$(x_0, p_0)$ 通过 QKD 或安全信道在 $t=0$ 时刻共享
2. **实时混沌演化**：双方同步求解 NL-SSF，生成混沌掩码 $C(t) = |\psi(x_{\text{ref}}, t)|^2$
3. **编码**：$\psi_{\text{tx}} = U_{\text{total}} \cdot (s \oplus C(t))$

**攻击者困境**：
- **时间窗口**：必须在 $<\Delta t$ 内完成截获、反解混沌态、预测下一时刻值、伪造并注入信号
- **物理不可能性**：混沌系统的正向计算是确定的，但**逆问题指数困难**，且**预测所需计算时间随精度要求指数增长**，超过物理时间本身

#### 4.4.3 与经典/量子层的协同

| 防御层 | 被突破条件 | 独立物理基础 |
|:---|:---|:---|
| **经典 SSF** | 亚微角秒定位 + 设备物理克隆 | 相对论 + 测量极限 |
| **量子 Q-SSF** | 量子克隆 + 局域隐变量 | 量子力学公理 |
| **混沌 C-SSF** | 时间反演 + 无穷精度 | 热力学第二定律 + 混沌理论 |

**安全叠加原理**：总安全强度 $S_{\text{total}} = S_{\text{classical}} \oplus S_{\text{quantum}} \oplus S_{\text{chaotic}}$，各层缺陷不累积（突破一层不自动突破其他层）。

**降级与恢复机制**：
- **异常检测**：若检测到 BER 异常（$>10^{-3}$）但量子层正常（贝尔测试通过），触发**混沌失步警报**
- **重新同步**：系统自动通过量子信道传输新初始条件 $(x_0', p_0')$

import numpy as np
import matplotlib.pyplot as plt
from numpy.fft import fft, ifft
from matplotlib.patches import Circle
import warnings

# ==================== 核心SSF协议 ====================

class SSFProtocol:
    """标准SSF协议（经典层）"""
    def __init__(self, N=64, M=4.0, dt=0.1, n_steps=10, seed=42):
        self.N = N
        self.M = M
        self.dt = dt
        self.n_steps = n_steps
        
        # 生成酉矩阵
        np.random.seed(seed)
        X = np.random.randn(N, N) + 1j*np.random.randn(N, N)
        self.U, _ = np.linalg.qr(X)
        self.U = self.U / np.sqrt(np.sum(np.abs(self.U**2), axis=0))
        self.U_dag = self.U.conj().T
        
        self.P = np.eye(N)
        self.P_inv = np.eye(N)
        self.constellation = np.array([1+1j, -1+1j, -1-1j, 1-1j]) / np.sqrt(2)
        
        # FFT相位因子
        k = np.fft.fftfreq(N, d=1.0) * 2 * np.pi * N
        self.phase = np.exp(-1j * (k**2) / (2*M) * dt)
        self.phase_inv = np.exp(+1j * (k**2) / (2*M) * dt)
    
    def bytes_to_symbols(self, data):
        """字节流转QPSK符号（每字节→4符号）"""
        symbols = []
        for byte in data:
            symbols.extend([
                (byte >> 6) & 0x3,
                (byte >> 4) & 0x3,
                (byte >> 2) & 0x3,
                byte & 0x3
            ])
        return np.array(symbols, dtype=int)
    
    def symbols_to_bytes(self, symbols):
        """QPSK符号转字节流"""
        # 补齐到4的倍数
        remainder = len(symbols) % 4
        if remainder != 0:
            symbols = np.concatenate([symbols, np.zeros(4 - remainder, dtype=int)])
        
        bytes_list = []
        for i in range(0, len(symbols), 4):
            byte = (symbols[i] << 6) | (symbols[i+1] << 4) | (symbols[i+2] << 2) | symbols[i+3]
            bytes_list.append(byte)
        return np.array(bytes_list, dtype=np.uint8)
    
    def encode(self, symbols):
        """编码：QPSK→SSF演化"""
        # 补齐到N
        if len(symbols) < self.N:
            symbols = np.concatenate([symbols, np.zeros(self.N - len(symbols), dtype=int)])
        
        rho = self.constellation[symbols % 4]
        rho = rho * np.sqrt(self.N / (np.sum(np.abs(rho)**2) + 1e-10))
        
        psi = self.P @ rho
        psi = self.U @ psi
        
        for _ in range(self.n_steps):
            psi_k = fft(psi)
            psi_k = psi_k * self.phase
            psi = ifft(psi_k)
        return psi
    
    def decode(self, psi_rx):
        """解码：SSF逆演化→QPSK"""
        psi = psi_rx.copy()
        for _ in range(self.n_steps):
            psi_k = fft(psi)
            psi_k = psi_k * self.phase_inv
            psi = ifft(psi_k)
        
        psi = self.U_dag @ psi
        rho = self.P_inv @ psi
        
        distances = np.abs(rho[:, None] - self.constellation[None, :])
        return np.argmin(distances, axis=1)
    
    def add_noise(self, signal, snr_db):
        """添加AWGN噪声"""
        if snr_db is None or snr_db == float('inf'):
            return signal
        signal_power = np.mean(np.abs(signal)**2)
        snr_linear = 10**(snr_db/10)
        noise_power = signal_power / snr_linear
        noise = (np.random.randn(self.N) + 1j*np.random.randn(self.N)) * np.sqrt(noise_power/2)
        return signal + noise
    
    def get_frame_capacity(self):
        """返回每帧承载的符号数"""
        return self.N

class QECProtocol(SSFProtocol):
    """QEC-SSF协议（量子纠错层）- 修正版"""
    def __init__(self, N=64, M=4.0, dt=0.1, n_steps=10, seed=42, delta=2):
        super().__init__(N, M, dt, n_steps, seed)
        self.delta = delta
        self.K = N // delta  # 逻辑码字数
    
    def get_frame_capacity(self):
        """QEC只使用K=N/δ个逻辑位置"""
        return self.K
    
    def encode(self, symbols):
        """QEC编码：符号映射到等间距码字位置"""
        # 补齐或截断到K
        if len(symbols) > self.K:
            symbols = symbols[:self.K]
        elif len(symbols) < self.K:
            symbols = np.concatenate([symbols, np.zeros(self.K - len(symbols), dtype=int)])
        
        # 构造N维向量，仅码字位置非零
        mapped = np.zeros(self.N, dtype=complex)
        codewords = np.arange(0, self.N, self.delta)
        
        for i, sym in enumerate(symbols):
            mapped[codewords[i]] = self.constellation[sym % 4]
        
        # 功率归一化
        mapped = mapped * np.sqrt(self.N / (np.sum(np.abs(mapped)**2) + 1e-10))
        
        # 标准SSF演化
        psi = self.P @ mapped
        psi = self.U @ psi
        for _ in range(self.n_steps):
            psi_k = fft(psi)
            psi_k = psi_k * self.phase
            psi = ifft(psi_k)
        
        return psi, codewords  # 返回码字位置供解码使用
    
    def decode(self, psi_rx, codewords=None):
        """QEC解码：只在码字位置采样"""
        if codewords is None:
            codewords = np.arange(0, self.N, self.delta)
        
        psi = psi_rx.copy()
        for _ in range(self.n_steps):
            psi_k = fft(psi)
            psi_k = psi_k * self.phase_inv
            psi = ifft(psi_k)
        
        psi = self.U_dag @ psi
        rho = self.P_inv @ psi
        
        # 只在码字位置硬判决
        symbols = []
        for idx in codewords:
            distances = np.abs(rho[idx] - self.constellation)
            sym = np.argmin(distances)
            symbols.append(sym)
        return np.array(symbols)

class ChaosProtocol(QECProtocol):
    """C-SSF协议（混沌增强层）"""
    def __init__(self, N=64, M=4.0, dt=0.1, n_steps=10, seed=42, delta=2, kappa=3.0, chaos_seed=12345):
        super().__init__(N, M, dt, n_steps, seed, delta)
        self.kappa = kappa
        self.chaos_seed = chaos_seed
        
        # 初始化混沌态（预共享密钥）
        np.random.seed(chaos_seed)
        self.psi_chaos_init = np.random.randn(N) + 1j*np.random.randn(N)
        self.psi_chaos_init /= np.linalg.norm(self.psi_chaos_init)
        
        # 预生成掩码序列（确保收发同步）
        self._precompute_masks()
    
    def _precompute_masks(self):
        """预计算混沌掩码，避免多次调用产生不同序列"""
        psi = self.psi_chaos_init.copy()
        self.chaos_masks = []
        
        for _ in range(self.n_steps):
            # NL-SSF单步演化
            phase_nl = np.exp(-1j * self.kappa * np.abs(psi)**2 * self.dt)
            psi_nl = psi * phase_nl
            
            k = np.fft.fftfreq(self.N, d=1.0) * 2 * np.pi * self.N
            phase_d = np.exp(-1j * (k**2) / (2*self.M) * self.dt)
            
            psi_k = fft(psi_nl)
            psi_k = psi_k * phase_d
            psi = ifft(psi_k)
            
            # 记录掩码（中心相位）
            mask = np.angle(psi[self.N//2]) % (2*np.pi) / (2*np.pi)
            self.chaos_masks.append(mask)
    
    def encode(self, symbols, use_chaos=True):
        """混沌增强编码"""
        # 先进行QEC编码
        psi, codewords = super().encode(symbols)
        
        if use_chaos:
            # 应用预计算的混沌掩码
            for i, mask in enumerate(self.chaos_masks):
                phase_shift = np.exp(2j * np.pi * mask * np.arange(self.N) / self.N)
                psi = psi * phase_shift
        
        return psi, codewords
    
    def decode(self, psi_rx, codewords=None, use_chaos=True):
        """混沌增强解码"""
        if use_chaos:
            # 逆序应用逆掩码（使用预计算的相同序列）
            for i in range(len(self.chaos_masks)-1, -1, -1):
                mask = self.chaos_masks[i]
                phase_shift_inv = np.exp(-2j * np.pi * mask * np.arange(self.N) / self.N)
                psi_rx = psi_rx * phase_shift_inv
        
        # QEC解码
        return super().decode(psi_rx, codewords)
    
    def estimate_lyapunov(self):
        """估计李雅普诺夫指数（定理8.3）"""
        delta = 1e-10
        psi1 = self.psi_chaos_init.copy()
        psi2 = psi1 + delta * (np.random.randn(self.N) + 1j*np.random.randn(self.N))
        psi2 /= np.linalg.norm(psi2)
        
        distances = []
        for _ in range(self.n_steps):
            # 单步演化
            phase_nl = np.exp(-1j * self.kappa * np.abs(psi1)**2 * self.dt)
            psi1 = ifft(fft(psi1 * phase_nl) * np.exp(-1j * (np.fft.fftfreq(self.N, d=1.0) * 2 * np.pi * self.N)**2 / (2*self.M) * self.dt))
            
            phase_nl = np.exp(-1j * self.kappa * np.abs(psi2)**2 * self.dt)
            psi2 = ifft(fft(psi2 * phase_nl) * np.exp(-1j * (np.fft.fftfreq(self.N, d=1.0) * 2 * np.pi * self.N)**2 / (2*self.M) * self.dt))
            
            dist = np.linalg.norm(psi1 - psi2)
            distances.append(dist)
            if dist > 1e-3:
                psi2 = psi1 + (psi2 - psi1) / dist * delta
        
        if len(distances) > 1:
            log_dists = np.log(np.array(distances) / delta)
            slope = np.polyfit(np.arange(len(distances)) * self.dt, log_dists, 1)[0]
            return max(slope, 0.01)
        return 0.1

# ==================== 图像传输系统（修正版） ====================

class BMPTransmissionSystem:
    """彩色BMP传输系统 - 统一接口"""
    def __init__(self, img_color):
        self.img = img_color
        self.H, self.W, self.C = img_color.shape
        self.header_size = 54
    
    def transmit(self, protocol, snr_db, use_chaos=False):
        """
        统一传输接口
        
        Args:
            protocol: SSFProtocol, QECProtocol, 或 ChaosProtocol 实例
            snr_db: 信噪比(dB)
            use_chaos: 是否启用混沌层（仅ChaosProtocol有效）
        """
        # 构造数据：文件头×3（Repeat3保护）+ RGB像素
        header = np.random.randint(0, 256, size=self.header_size, dtype=np.uint8)
        payload = np.concatenate([
            self.img[:,:,0].flatten(),
            self.img[:,:,1].flatten(),
            self.img[:,:,2].flatten()
        ])
        data = np.concatenate([np.tile(header, 3), payload])
        
        # 转符号
        symbols = protocol.bytes_to_symbols(data)
        
        # 分帧传输
        frame_cap = protocol.get_frame_capacity()
        rx_symbols = []
        total_errors = 0
        total_symbols = 0
        
        # 补齐到帧边界
        padding = (frame_cap - (len(symbols) % frame_cap)) % frame_cap
        symbols = np.concatenate([symbols, np.zeros(padding, dtype=int)])
        
        # 逐帧处理
        for i in range(0, len(symbols), frame_cap):
            frame = symbols[i:i+frame_cap]
            
            # 编码
            if isinstance(protocol, ChaosProtocol):
                psi_tx, cw = protocol.encode(frame, use_chaos=use_chaos)
                psi_rx = protocol.add_noise(psi_tx, snr_db)
                rx_frame = protocol.decode(psi_rx, cw, use_chaos=use_chaos)
            elif isinstance(protocol, QECProtocol):
                psi_tx, cw = protocol.encode(frame)
                psi_rx = protocol.add_noise(psi_tx, snr_db)
                rx_frame = protocol.decode(psi_rx, cw)
            else:  # Standard SSF
                psi_tx = protocol.encode(frame)
                psi_rx = protocol.add_noise(psi_tx, snr_db)
                rx_frame = protocol.decode(psi_rx)
            
            # 统计
            actual_len = min(len(frame), len(rx_frame))
            errors = np.sum(rx_frame[:actual_len] != frame[:actual_len])
            total_errors += errors
            total_symbols += len(frame)
            
            rx_symbols.extend(rx_frame[:actual_len])
        
        # 重建图像
        rx_symbols = np.array(rx_symbols[:len(data)])
        rx_bytes = protocol.symbols_to_bytes(rx_symbols)
        
        rx_img = np.zeros_like(self.img)
        if len(rx_bytes) >= 3*self.header_size:
            rx_payload = rx_bytes[3*self.header_size:3*self.header_size+len(payload)]
            if len(rx_payload) >= len(payload):
                cs = self.H * self.W
                rx_img[:,:,0] = rx_payload[0:cs].reshape(self.H, self.W)
                rx_img[:,:,1] = rx_payload[cs:2*cs].reshape(self.H, self.W)
                rx_img[:,:,2] = rx_payload[2*cs:3*cs].reshape(self.H, self.W)
        
        ber = total_errors / total_symbols if total_symbols > 0 else 0
        return rx_img, ber

def calculate_psnr(img1, img2):
    """计算彩色图像PSNR"""
    mse = np.mean((img1.astype(float) - img2.astype(float))**2)
    if mse == 0:
        return float('inf')
    return 20 * np.log10(255.0 / np.sqrt(mse))
