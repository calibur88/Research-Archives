# 量子通信路径积分模型

## 1. 配分函数

$$Z[\mathcal{K}] = \int \mathcal{D}[\psi, \psi^{\ast}] \, \exp\left( i S_{\text{eff}}[\psi, \psi^{\ast}; \mathcal{K}] \right)$$

## 2. 有效作用量

$$S_{\text{eff}}[\psi, \psi^{\ast}; \mathcal{K}] = \int_{0}^{T} dt \int d^d x \, \mathcal{L}[\psi]$$

### 拉格朗日密度

$$\mathcal{L}[\psi] = \psi^{\ast} i\partial_t \psi + \frac{1}{2M}\psi^{\ast}\nabla^2\psi + \frac{\kappa_{\text{nl}}}{2}|\psi|^4 + \int d^d x' \, \psi^{\ast}(x) U_{\text{polar}}(x,x') \psi(x')$$

**参数说明：**
- $T = n_s \Delta t$：总演化时间
- $\kappa_{\text{nl}}$：非线性耦合系数（Kerr效应）
- $U_{\text{polar}} \in \mathrm{U}(N)$：极化编码酉矩阵

## 3. 离散化配分函数

$$Z[\mathcal{K}] = \int \left( \prod_{j=0}^{n_s-1} \prod_{n=-D}^{D} \frac{d\psi_n^{(j)} d\psi_n^{\ast(j)}}{\mathcal{A}} \right) \exp\left( i \Delta t \sum_{j=0}^{n_s-1} \mathcal{L}_{\text{disc}}^{(j)} \right)$$

**参数：**
- $\mathcal{A} = 2\pi / \Delta t$：归一化常数
- $n_s$：时间步数（正整数）
- $N = 2D+1$：空间格点总数
- $j \in \{0, 1, \dots, n_s-1\}$：时间层索引
- $n \in \{-D, \dots, D\}$：空间格点索引

## 4. 离散拉格朗日量

$$\mathcal{L}_{\text{disc}}^{(j)} = \sum_{n=-D}^{D} \psi_n^{\ast(j)} \left[ i\frac{\psi_n^{(j+1)} - \psi_n^{(j)}}{\Delta t} + \frac{1}{2M}\nabla^2_{\text{disc}} \psi_n^{(j)} + \kappa_{\text{nl}} |\psi_n^{(j)}|^2 \psi_n^{(j)} + \sum_{m=-D}^{D} U_{n,m}^{\text{polar}} \psi_m^{(j)} \right]$$

### 离散拉普拉斯算子

$$\nabla^2_{\text{disc}} \psi_n^{(j)} = \psi_{n+1}^{(j)} - 2\psi_n^{(j)} + \psi_{n-1}^{(j)}$$

**边界条件：** 周期性边界条件（匹配傅里叶谱方法）

## 5. 密钥空间参数定义

$$\mathcal{K} = \{M, \Delta t, n_s, U_{\text{polar}}, \kappa_{\text{nl}}, N, \text{seed}\}$$

| 参数 | 取值范围 | 物理意义 |
|------|----------|----------|
| $M$ | $[2.0, 8.0]$ | 归一化通信距离（色散控制参数，$M$越大色散越弱） |
| $\Delta t$ | $[0.01, 0.20]\,\mathrm{s}$ | 时间演化步长 |
| $n_s$ | $[5, 50] \subset \mathbb{Z}^{+}$ | 总演化步数 |
| $N = 2D+1$ | $\{33, 65, 129, \dots\}$ | 空间离散维度（奇数） |
| $U_{\text{polar}}$ | $\in \mathrm{U}(N)$ | 厄米酉矩阵，满足 $U_{\text{polar}}^{\dagger} = U_{\text{polar}}$ |
| $\kappa_{\text{nl}}$ | $[1.5, 5.0]$ | 非线性耦合系数（克尔效应强度） |
| $\text{seed}$ | $[0, 2^{256})$ | 256位密码学随机数种子 |

## 6. 坐标与色散关系

### 实空间格点

$$x_n = n \Delta x$$

其中 $\Delta x = 1.0$，格点索引 $n = -D, -D+1, \dots, D$

### 倒空间格点

$$k_j = \frac{2\pi j}{N \Delta x}$$

其中 $j = -\frac{N-1}{2}, \dots, \frac{N-1}{2}$，且 $j \in \mathbb{Z}$

### 色散律

$$\omega(k; M) = \frac{k^2}{2M} \quad (\text{Schrödinger型})$$

## 7. 酉演化算符（SSF格式）

### 单步线性演化算符

$$\mathcal{U}_{\text{step}}(M) = \mathcal{F}^{-1} \circ \exp\left( -i \frac{k^2}{2M}\Delta t \right) \circ \mathcal{F}$$

### 总酉演化算符（先编码后传输）

$$\mathcal{U}_{\text{tot}}(M) = \left( \mathcal{U}_{\text{step}}(M) \right)^{n_s} \cdot U_{\text{polar}}$$

### 态演化

$$\psi(T) = \mathcal{U}_{\text{tot}}(M) \, \psi(0)$$

> **注：** $\mathcal{U}$（花体）专指时间演化算符，$U$（正体）专指极化编码矩阵。

## 8. 辛几何结构（C-SSF）

### 正则分解

$$\psi_n = q_n + i p_n$$

正则向量 $\mathbf{\Gamma} = (q_{-D}, \dots, q_D, p_{-D}, \dots, p_D)^{\mathrm{T}} \in \mathbb{R}^{2N}$

### 标准辛矩阵

$$J = \begin{pmatrix} 0_N & I_N \\ -I_N & 0_N \end{pmatrix}$$

### 三阶辛条件

$$\mathcal{U}_{\text{NL}}^{\mathrm{T}} J \, \mathcal{U}_{\text{NL}} = J + \mathcal{O}(\Delta t^3)$$

其中 $\mathcal{U}_{\text{NL}}$ 为非线性演化算符，保证长时演化的数值稳定性与哈密顿量守恒。
