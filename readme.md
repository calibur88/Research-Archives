# Research-Archives

个人研究档案库：数学、物理、宇宙学、几何与形式系统、工程技术、哲学六个领域的原创研究笔记，配套 Python 验证脚本、LaTeX 排版稿与图表。

## 目录结构

```
Research-Archives/
├── 首页.md                 # 知识库门户
├── readme.md               # 本文件：仓库说明 / 联系 / 协议
├── MOC/                    # 六张领域地图（Map of Content）
├── _meta/                  # 笔记模板与标签体系
├── 01-数学与猜想/           # 数学、黎曼猜想、拉马努金、挂谷猜想
├── 02-物理与量子/           # NS方程、量子、杨米尔斯猜想
├── 03-宇宙学/               # 标准宇宙模型、自创宇宙模型
├── 04-几何与形式系统/       # 几何（DCG）、形式系统（FACS）
├── 05-工程与技术/           # 星际航行、光追技术、量子通讯玩具版
└── 06-哲学与方法论/         # 哲学反思
```

每个主题文件夹内：`*.md` 笔记正文 + `图片/` 图表 + `latex/` 排版稿 + 验证脚本（按需）。

## 使用方式

推荐用 [Obsidian](https://obsidian.md) 打开仓库根目录：双链 `[[...]]` 跳转、关系图谱、标签检索开箱即用。任何纯 Markdown 编辑器均可正常阅读。

## 文档规范

每篇笔记头部含 YAML frontmatter：

| 字段 | 说明 |
|---|---|
| title | 展示标题 |
| domain | 领域：数学 / 物理 / 宇宙学 / 几何 / 形式系统 / 工程 / 哲学 |
| tags | 细分主题标签（命名规范见 `_meta/标签体系.md`） |
| status | 成稿 / 草稿 / 探索 / 素材 |
| type | 证明 / 建模 / 论证 / 综述 / 规范 / 工具 / 随笔 |
| created / updated | 创建 / 最后修改日期 |
| summary | 一句话摘要 |
| related | 相关笔记双链 |
| assets | 配套脚本 / 排版稿 / 图片清单 |

新笔记模板见 `_meta/模板-研究笔记.md`。
