# MOC-宇宙学

两条互补的线：**批判线**用讽刺与证伪解构 ΛCDM 的防御语法；**建构线**给出自创的宇宙模型与现象学纲领。两线共享脉冲星计时阵列（PTA）与 JWST 观测证据。

## 批判叙事线（标准宇宙模型）

- [[LambdaCDM_Richness_Memo]] — 讽刺 ΛCDM「全观测免疫」的再描述机制
- [[天球异常丰富书]] — 天球偶极僵局：七层防御解构 + 六判据证伪 FLRW 各向同性
- [[乐子文]] — NANOGrav 九论文并置，诊断五组互斥结论
- [[《GIM丰饶范式全书》]] — 十二卷拟圣经戏仿 ΛCDM 防御语法
- [[宇宙认识]] — ζ(0.5) 调制破缺与 0.5 轴心围道创生叙事（探索稿）

## 建构线（自创宇宙模型）

- [[DDGT唯象宇宙模型]] — 离散对偶空间粗粒化导出时空与质量谱（主纲领）
- [[weyl-cft]] — 四色定理推导母作用量，涌现轨道力学 / 暗物质 / 暗能量
- [[ER=EPR]] — 从 BEC 作用量严格推导 ER=EPR 算子等式
- [[CVOD_Framework]] — 级联挥发-轨道重构：开放系统解释天体演化
- [[3IATLAS]] — 3I/ATLAS 异常观测汇编与厚盘起源解释
- [[异型流形]] — PTA 三重全局结构 + 图兰定理，否定 ΛCDM 补丁策略
- [[density_driven_QFT]] — 密度为基本自由度的紫外完备 QFT（草稿）
- [[LRD]] — JWST 小红点观测证据汇编（素材）
