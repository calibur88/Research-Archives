# 环面拮抗聚变（Toroidal Antagonist Fusion, TAF）  
## 概念框架文档

### 1. 框架定位

TAF 是一个**磁-惯性混合约束聚变范式**，旨在从几何与热力学层面重新定义聚变系统的设计逻辑。它不追求完美边界约束，而是以**熵流拓扑**为核心，将燃烧波定义为从“负熵注入点”向“熵排出点”定向传播的不可逆过程，通过几何结构自动引导燃烧波沿允许路径传播，将熵增物理地排出系统。

### 2. 本质定义

TAF 的本质是一种**基于几何拮抗的熵流管理方案**。系统采用**墨西哥帽几何**（中心凸起‑帽沿下沉）作为统一原理，将聚变燃烧组织为一条从帽顶（负熵注入）到帽沿（正熵排出）的单向路径。系统稳态不再依赖理想约束，而是依赖**熵流入 = 熵流出**的动态平衡。

### 3. 核心机制

| 层级 | 核心内容 | 物理对应 / 依据 |
|------|----------|----------------|
| **燃烧波物理** | 磁化热斑点火后，燃烧波沿磁场方向各向异性传播 | NIF 磁化实验（PoP 2024）证实：轴向传播优先，径向抑制 |
| **墨西哥帽几何** | 中心强磁场（约束 α 粒子）→ 帽沿弱磁场 / 开放（排出熵） | MagLIF 柱形压缩 + 轴向排气，自然形成中心‑周围拮抗 |
| **熵流拓扑** | 帽顶注入负熵（压缩能、磁能），帽沿排出正熵（废热、灰分、中子） | 燃烧波作为连接顶与沿的不可逆路径，系统稳态依赖连续熵流 |
| **脉冲循环** | 压缩‑点火‑燃烧‑膨胀‑排灰‑加料，周期重置熵状态 | 套筒可牺牲/可替换，第一壁作为耗散界面 |

### 4. 设计哲学

TAF 体现了一种从**对抗**到**疏导**的范式转变：

- **主流路线**（托卡马克、仿星器等）：用强磁场压制等离子体不稳定性，追求完美约束与稳态运行。
- **TAF 路线**：承认熵增不可逆，主动为熵提供低阻抗排出通道，将约束的“硬指标”转化为熵流拓扑的“几何设计”。

这种思路将原本被视为“问题”的现象（边界不稳定性、氦灰积累、脉冲运行）重新定义为系统正常工作的表现或可管理的工程要素。

### 5. 关键技术特征

- **磁场位形**：中心强场区维持 α 粒子加热与自持燃烧，边缘弱场/开放区利用磁镜效应或磁岛结构优先排出废热与灰分。
- **燃烧波传播**：利用磁化燃烧的各向异性，确保燃烧波沿轴向从帽顶向帽沿单向传播，避免热斑漂移与能量弥散。
- **周期重置**：通过脉冲运行，每个周期结束后更换耗散界面（套筒/第一壁），将累积损伤从物理问题转为工程维护问题。

### 6. 与现有实验的呼应

- **NIF 磁化实验（2024）**：验证了在磁化等离子体中，燃烧波可沿磁场方向优先传播，径向受到抑制，为 TAF 的燃烧波物理提供了实验支撑。
- **MagLIF（磁化线性惯性聚变）**：柱形压缩与轴向排气的思路与 TAF 的“墨西哥帽”几何在拓扑上具有相似性，表明轴向开放结构在工程上具有可行性。
